About Lost & Found Portal

This portal helps students and staff report lost or found items on campus.

How It Works

  • Report Lost: If you've lost an item, create a report with details.
  • Report Found: If you've found an item, create a report to help find the owner.
  • Search: Use filters to find specific items.
  • Claim: If you see your item, contact the reporter.

Rules

  • Be honest and accurate when reporting items.
  • Provide clear descriptions and locations.
  • Update status when items are returned or claimed.
  • Respect others' property and privacy.

Contact

For any issues, contact the campus security or help desk.
