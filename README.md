# Lost & Found Portal

A complete Lost & Found management system for university students and staff.

## Features

- 📊 Dashboard with statistics
- 🔍 Search, filter, and sort items
- 📋 Full CRUD operations
- 📱 Responsive design
- 💾 JSON file storage
- 🚀 RESTful API

## Technologies

- **Backend**: Node.js, Express.js
- **Frontend**: HTML5, CSS3, Vanilla JavaScript
- **Storage**: JSON File System
- **API**: RESTful with Fetch API
